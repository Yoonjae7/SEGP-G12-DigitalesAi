Voice casting sheet

Voices are made with ElevenLabs at build time, from team-approved text. The key never reaches the browser. The team picks each voice from the ElevenLabs library using these notes and pastes the IDs into voices.json. Settings below are starting points, tune them by ear. Chat lines are voiced in the sender’s voice. Screen text is not voiced. The learner has no voice.

Pipeline and fallbacks

  • Generated at build time. One mp3 per line, named by the line ID, such as s1_01.mp3. Cached by a hash of speaker, text and voice, so only changed lines are made again.
  • Starts muted. The learner taps “Play with sound”. Each line has a replay button. Preloaded one scene ahead.
  • If a file is missing or fails, captions only, and the story carries on. Audio never blocks.
  • If ElevenLabs keeps failing, the team can make the files from the line list below and drop them in public/audio with the same names.
