Character sheets

Five people, drawn as matte clay. The 3D build uses capsule bodies, squashed sphere heads and small sphere hands, and every figure here uses the same joints. These flat versions are also the cut-outs for “Simple visuals”.

MaterialMatte clay. No gloss, no realistic skin.
OutlineThin ink line from an inverted-hull pass. A little wobble, so it looks hand-inked.
ShadingToon, three steps: light, base, shade. Light from top left. Shadows lean cool.
FacesTwo dots, brow lines, a small mouth. Expressions swap by changing the face texture.
ShadowA baked contact blob under the feet. No real-time shadows.

Cast, to scale

Sarah is the shortest. Lisa is the tallest. Marco is the roundest. Dev is the thinnest. Skin and hair colours are varied across the cast and are not tied to role or personality.

Pose library

Nine procedural poses, shown on Lisa. Each pose is a table of joint rotations (head, shoulders, elbows) with an ease between them, 400 to 600 ms. A pose is a string in story.json, so changing it never needs a code change.

PoseShoulder LElbow LShoulder RElbow RLeanHead rollHead nodUsed for

Shoulder is the upper arm angle from hanging straight down, in degrees, positive away from the body. Elbow is the extra turn of the forearm: positive opens it outward and up, negative folds it inward. Lean is the whole upper body about the hips. Head nod is positive when looking down. The build reads this table directly.

Build route

  • Default: characters built in code from primitives (capsule body, squashed sphere head, small sphere hands) with react-three-fiber. Poses are joint tables. Faces are a texture atlas, one cell per expression.
  • Swap later: a CharacterModel interface lets GLB models replace them at /public/models/*.glb without touching scene code. The build never waits for model files.
  • Fallback: “Simple visuals” uses the flat cut-outs on this page, same colours, same poses.
  • The photo: never depicted. Always a blurred stripe tile labelled “Photo (hidden)”.
